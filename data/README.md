# Measurement Data
This directory contains measurement data of all measurement campaigns done on the ULNLDD v0.3 and companion boards.

Unfortunately since all measurements span multiple gigabytes worth of data, not everything is uploaded in this repository.
We tried to select some data samples so that one can take an idea how the whole dataset looks like.
If you want some data files for whatever reason, shoot an email we'll reply as soon as possible with the necessary
data files.
